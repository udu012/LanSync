重新生成使用说明长图
====================

这个目录是「使用说明.png」的源文件，改完文案后可以自己重新出图。

文件说明
--------
使用说明源文件.html   文案与排版（改这里）
shot_dash2.png        看板截图素材（电脑端界面）
qr_demo.png           二维码素材（手机示意图里用）
chg_card.png          「更改接收目录」按钮位置（第七节配图，按钮带橙色描边）
chg_modal.png         更换目录的确认弹层（第七节配图）

重新出图
--------
需要 Chromium 或 Chrome。在命令行执行：

  chrome --headless --disable-gpu --hide-scrollbars \
         --window-size=1080,1200 \
         --screenshot="使用说明.png" \
         "使用说明源文件.html"

或者在浏览器里直接打开 html，用「打印 → 另存为 PDF」也能得到一份可发的文档。

注意
----
1. 页面宽度固定 1080px，不要改窄，否则步骤编号和竖线会错位。
2. 看板截图是用 Playwright 截的，视口 1280x940、deviceScaleFactor=2。
   重新截的话记得把接收目录换成 Windows 路径（D:\LanSync\接收文件），
   否则图里会出现 Linux 路径，用户会困惑。
3. 图片是 2 倍图（2160 宽），在高分屏和微信里都清晰。
4. 第七节两张配图的截法：打开看板后给 #chgdir 注入
   box-shadow:0 0 0 2.5px #f59e0b 做成橙色高亮，再对 .card.stat 元素截图；
   弹层图先点「更改」→ 填路径 → 点「下一步」，再把 main 和 header 设为
   visibility:hidden，让四周只剩干净的遮罩。
