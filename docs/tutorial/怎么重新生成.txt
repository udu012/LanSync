重新出图
--------
需要 Chromium 或 Chrome。在命令行执行：

  chrome --headless --disable-gpu --hide-scrollbars \
         --window-size=1080,1200 \
         --screenshot="使用说明.png" \
         "使用说明源文件.html"

或者在浏览器里直接打开 html，用「打印 → 另存为 PDF」也能得到一份可发的文档。

注意
----
1. 页面宽度固定 1080px，不要改窄，否则步骤编号和竖线会错位。
2. 整页截图用 Playwright，视口 1280x1120、deviceScaleFactor=2、full_page=True。
   截之前必须把 #dir 的文本换成 Windows 路径
   （C:\Users\Administrator\Documents\LanSync），否则图里会出现沙箱的
   /tmp/... 路径，用户看了会困惑。
3. 第二节概览图的截法：打开看板后给 #chgdir 注入
     color:#b45309;border-color:#f59e0b;background:#fffaeb;
     box-shadow:0 0 0 4px rgba(245,158,11,.16)
   做成橙色高亮，再对 #dir 最近的 section.card 元素截图（1360x544）。
4. 弹层图（chg_modal.png）先点「更改」→ 填路径 → 点「下一步」，
   再把 main 和 header 设成 visibility:hidden，让四周只剩干净的遮罩。
5. 图是 2 倍图（2160 宽），高分屏和微信里都清晰；整张高度一万多像素，
   手机端查看需要可缩放的图片查看器（别用普通 ImageView 直接铺满）。
6. 生成后务必抽查：标题序号是否连续、图注是否和正文对得上、
   有没有残留 Linux 路径。

App 里的说明（同一篇文案的另一种排版）
--------------------------------------
app/app/src/main/assets/guide/guide.html 是打包进 APK 的自适应版，
App 主界面底部「使用说明」打开的就是它（WebView 加载 file:///android_asset/guide/guide.html）。

和 使用说明源文件.html 的差别只有排版，文字逐字一致：

1. 去掉 body 的固定 1080px，改成 max-width:1080px + 居中
2. 多一套 @media (max-width:820px)：字号、内边距、步骤圆圈收小，
   .split 从两列变一列（手机示意图移到文字下方），配图圆角变小
3. 配图换成同目录的 g_*.webp（由这些 png 压出来，quality≈82，长边 2160），
   WebP 比 png 小一半以上，6 张合计 281KB
4. 配图可点开：2 倍宽铺满屏幕，左右拖动看细节（看板截图缩到 340px 宽必然看不清）
5. 多一套 .lb / .zoom 样式和 40 行 JS，仅此而已

改文案时两份都要改，否则 App 里和长图说的会不一样。
